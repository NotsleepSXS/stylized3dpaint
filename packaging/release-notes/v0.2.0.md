**Stylized3DPaint 0.2** — masks by polygons, painting on the UV view, a content browser with
presets, a UV checker map, and a fix for the Windows build not starting.

### Downloads
| System | File | How |
|---|---|---|
| **Linux** (x86_64) | `Stylized3DPaint-0.2.0-linux-x86_64.tar.gz` | unpack, run `./install.sh` (user install: app menu entry, `stylized3dpaint` command, `.s3dp` files) — or just run `./stylized3dpaint` |
| **Windows** (x64) | `Stylized3DPaint-0.2.0-windows-x64-setup.exe` | installer (Start menu, optional desktop icon and `.s3dp` association) |
| Windows portable | `Stylized3DPaint-0.2.0-windows-x64-portable.zip` | unzip and run |

Needs a GPU with Vulkan (Linux) or DirectX 12 / Vulkan (Windows).

### New
- **Polygon Fill** tool (P): fill by **face**, **mesh part** or **UV island** — in the 3D view
  and on the UV view. On a mask it reveals (white) or hides (black) the picked parts; drag to
  fill several at once.
- Mode-aware wireframe overlay: quads are drawn as quads, UV-island borders, part borders; only
  what faces the camera is shown (no show-through).
- **Painting on the UV view** (3D + UV mode).
- **Content browser** panel: preset materials, preset masks and effects with thumbnails;
  double-click or drag to apply; save your own from a layer or a mask (`.s3dmat` / `.s3dmask`).
- **UV Checker** view mode: a lettered 512 checker map tiled by the texture size (1 tile at 512,
  2×2 at 1024, 4×4 at 2048…), so texel density and flipped UVs are easy to see.
- Noise and other generators get the **Seamless (3D)** toggle (drives their blur).

### Fixes
- **Windows: the app did not start.** Shaders are now compiled with the bundled DXC compiler
  (the default FXC failed on the effect shaders), the C runtime is linked statically (no Visual C++
  redistributable needed), and a startup error now shows a message with the log path instead of
  closing silently. The test suite now also runs on Windows CI.
- Renaming a layer: Enter applies the name.
- Smoother brush strokes on heavy dabs (per-frame dab budget); several polygon-fill and overlay
  fixes found in review.

Known issue: on software DirectX 12 (WARP) the Stylization filter can skip roughness / metallic;
if you see that on a real GPU, start with `WGPU_BACKEND=vulkan` and please report it.

**First public version** of Stylized3DPaint — an open-source 3D texture painter for stylized /
hand-painted texturing. It is early (0.1): usable for real work, but expect rough edges — please
report problems in [Issues](https://github.com/NotsleepSXS/stylized3dpaint/issues).

### Downloads
| System | File | How |
|---|---|---|
| **Linux** (x86_64) | `Stylized3DPaint-0.1.0-linux-x86_64.tar.gz` | unpack, run `./install.sh` (user install: app menu entry, `stylized3dpaint` command, `.s3dp` files) — or just run `./stylized3dpaint` |
| **Windows** (x64) | `Stylized3DPaint-0.1.0-windows-x64-setup.exe` | installer (Start menu, optional desktop icon and `.s3dp` association) |
| Windows portable | `Stylized3DPaint-0.1.0-windows-x64-portable.zip` | unzip and run |

Needs a GPU with Vulkan (Linux) or DirectX 12 / Vulkan (Windows). Linux is the main platform
(native Wayland with pen pressure; X11 works without pressure); the Windows build is new and
less tested.

### Highlights
- Texture-space brush painting with layers, folders, masks, 18 blend modes, all PBR channels
- GPU mesh-map baking (Realistic / Stylized), from the mesh or a high-poly
- Declarative effects: wear (edge wear, rust, scratches, chips…), stylization (Stylization
  master filter acting on every channel, toon, posterize, palette…), filters with a
  **seamless (3D)** mode across UV seams
- Graphical editors (gradient, levels, ranges, direction sphere) and per-effect previews on
  sample shapes
- HDRI lighting with 8 built-in Poly Haven maps, your own HDRIs, rotation (Shift + right-drag)
- Dockable panels, 3D + UV viewport, Russian / English UI
- Export presets: Unreal, Unity URP / HDRP, Godot, glTF, Sketchfab, Stylized Unlit… with the
  height baked into the normal map

### Clean-room
Written from scratch: no Substance 3D Painter source code, binaries, shaders or assets were
used or examined — only general texturing concepts, designed from the start for stylized work.
Substance 3D Painter is a trademark of Adobe; this project is not affiliated with Adobe.
